Privacy policy

Last updated: October 4, 2026

This OAuth client ("rclone") is used only by its owner for personal use, to let the open-source rclone tool access the owner's own Google Drive.

Data accessed

With the user's consent, rclone accesses Google Drive files and metadata in order to list, copy, sync, upload and download files as directed by the user on their own computer.

Data storage and sharing

  • No data is sent to, collected by, or stored on any server operated by the owner of this client.
  • OAuth tokens are stored only locally in the user's rclone configuration file.
  • No data is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
